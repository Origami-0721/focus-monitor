# focus-monitor

用笔记本前置摄像头 + Windows 前台窗口，长期记录你的专注状态，并分析**你几点最容易进入心流**。

不是番茄钟，不是时间统计软件。它想回答的是：**我什么时段、什么条件下能最快进入状态、能撑多久。**

## 功能

- **双路判定**：摄像头看"人在不在、看没看屏幕"，Win32 API 看"在用什么软件"。缺一路都判不准
- **五种状态**：专注 / 中性 / 伏案 / 走神 / 疲劳 / 离开
- **前台托盘常驻**：开机自启，无窗口，改配置不用改代码；托盘菜单直接显示当前状态和今日累计投入喵
- **实时面板**：本地网页，每 3 秒刷新当前状态、心流进度、今日累计；暂停时显示「已暂停」，不会误报成程序挂了喵
- **规律报告**：会话切分、心流片段、黄金时段排行；另有近 14 天每日投入柱状图、平均每天的小时节律、CSV 原始数据导出喵
- **全程本地**：不保存任何图像、不联网上传

## 工作原理

### 三路视觉信号

| 信号 | 做法 |
|---|---|
| 头部朝向 | MediaPipe FaceLandmarker 取 6 个关键点，`solvePnP` 解出鼻尖在相机坐标系的方向角 |
| 眼睛闭合 | 眼睛纵横比 EAR，持续低于阈值判疲劳 |
| 坐姿 | PoseLandmarker 肩线倾角 + 人脸尺度变化（是否越凑越近） |

> 头部姿态没有用欧拉角分解。实测那套公式在俯仰上会整体翻转 180°（中位数 171.7°），
> 改用鼻尖方向角 `atan2(ty, tz)`——对 3D 模型尺寸不敏感，稳得多。

### 状态机

```
离开   ← 键鼠空闲 / 人脸消失 超过阈值
疲劳   ← 持续闭眼
专注   ← 看着屏幕 + 工作应用
中性   ← 看着屏幕 + 未分类应用
伏案   ← 低头对桌子（看书/写作业）
走神   ← 在看分心应用，或转头/低头过狠
```

### 走神的两种成因

报告把走神拆成 **应用导致的** 和 **人没看屏幕** 两部分。这个区分很重要——前者靠屏蔽应用，后者靠休息或换任务，解法相反。混在一起会得出"快速设置是你最大分心源"这种荒谬结论。

## 安装

需要 Windows 和一个前置摄像头。

**不想折腾环境**：直接去 [Releases 页面](https://github.com/Origami-0721/focus-monitor/releases) 下载 `focus-monitor.exe`，
双击就能用喵 —— 不需要装 Python，也不需要命令行，数据（focus.db、日志、报告、CSV）都会存在 exe 旁边，怎么都不会丢喵。

想从源码跑：

```powershell
uv run focus.py --selftest        # 自检，不开摄像头
uv run focus.py                   # 开始监视（托盘图标）
```

首次运行会自动下载两个 MediaPipe 模型（约 11MB）。

> 依赖要求在 `pyproject.toml` 里锁了 `>=3.11,<3.13`。MediaPipe 目前没有 3.13+ 的 wheel，
> 用 uv 会自动拉一个兼容的解释器。

## 使用

```powershell
uv run focus.py                    # 托盘常驻（图标在任务栏的 ^ 折叠区里）
uv run focus.py --dashboard        # 实时面板 http://127.0.0.1:8787/
uv run focus.py --report           # 生成 HTML 报告并打开
uv run focus.py --install-startup  # 装开机自启
uv run focus.py --selftest         # 跑自检
```

生成报告的同时会在同目录写一份 `focus-日期.csv`（UTF-8 BOM + 表头，
Excel 直接双击就能打开），方便自己拿去统计喵。

### 托盘图标

| 操作 | 效果 |
|---|---|
| **左键单击** | 有待评分 → 直接打开评分页；否则 → 打开面板 |
| 右键 | 菜单：打开面板 / 自述评分 / 生成报告 / 暂停 / 退出 |

菜单最上面两行是只读信息，跟着实时状态走：**当前状态** 和 **今日累计投入**。
不用打开面板就能瞄一眼今天投入了多少喵。

> 系统气泡（提醒打分那个）**点了没反应是正常的** —— pystray 只处理左键和右键，
> 没有接 `NIN_BALLOONUSERCLICK`。所以提醒文案直接写了"点托盘图标"，
> 那才是可靠路径。

### 桌面开关

```powershell
uv run focus.py --install-shortcut
```

会在桌面建一个**「专注监视」**快捷方式，双击即切换开/关：

| 图标 | 状态 |
|---|---|
| 绿点 | 正在记录 |
| 灰底横杠 | 已停止 |

快捷方式的图标是静态的，所以每次切换时脚本会连 `.lnk` 一起重写，Explorer 立刻刷新。
开启时会另起一个游离进程，等面板就绪后再自动打开浏览器（模型加载要十几秒，
立刻打开只会看到「无法连接」）。

### 配置

打开实时面板 → **设置**。所有阈值、应用分类、行为开关都能在网页上改，**保存后 1 秒内生效，不用重启**，写入 `config.json`。

## 分析模型

- **会话**：一次"坐下来用电脑"。样本空档 >2 分钟（待机/关机）或连续离开 >15 分钟，都算会话结束
- **心流**：会话内连续投入 ≥15 分钟，**允许中间有 ≤60 秒的短暂中断**（挠头、喝水不该掐断记录）
- **进入心流耗时**：从坐下到第一段心流开始。按时段聚合，就是"黄金时段"那张表

黄金时段只统计**累积满 10 分钟**的钟点，避免拿几秒的样本编出"100% 专注"的假排名。

## 报告的图表

报告里的柱状图全部是内联 CSS + SVG 画出来的，没有引任何图表库，所以报告始终是**单文件 HTML**，拷走就能看喵。

- **近 14 天每日投入**：每天一根柱，悬停看当天投入时长和专注率。只显示有记录的自然日
- **全天活跃分布**：按「平均每天」归一化 —— 只有部分天用电脑的钟点不会被少有的几天撑虚高，看的是作息节律而不是总量喵
- **黄金时段 / 状态分布 / 时间轴**：沿用原有分析，排行和结论不受归一化影响

## 自述对照（数据到底准不准）

工具本身只会输出数字，没有任何东西能证明那些数字和你的真实感受对得上。
所以加了一层**自述评分**：每 30 分钟一块，你凭感觉打 1–5 分，然后和实测投入率做相关性。

**一条硬约束**：评分界面**不显示任何实测数据**。要是写着"这段测出 85% 专注"，
你会被那个数字锚定，收集到的就不是独立评价，没法用来验证任何东西。

**什么时候提醒你打分**：只在自然断点。如果检测到你正处在连续投入里（≥5 分钟），
提醒会自动推迟 —— 在人专注正盛的时候弹窗是本末倒置。一直专注就一直不问，
因为那本来就是想要的状态，没什么好打分的。

相关性会直接印在报告上：

| 相关系数 | 含义 |
|---|---|
| ≥ 0.7 | 测出来的和感受到的是一回事，数据可信 |
| 0.4 – 0.7 | 大方向对得上，阈值还有调的空间 |
| < 0.4 | 对不上，先调阈值，别急着信报告里的其他结论 |

样本少于 8 对时不给结论 —— 别拿三个点算相关系数。

## 隐私

- 所有处理在本地完成，**不保存任何图像**，不联网上传
- 磁盘上只有 `focus.db` 里的数值指标（角度、时长）和窗口标题
- 实时面板只监听 `127.0.0.1`，不对外网开放
- `.gitignore` 已排除 `focus.db` / `focus.log` / `config.json` —— 提交前请确认

## 已知限制

- **分不清"低头看书"和"低头玩手机"**。前置摄像头从正面拍，两者画面几乎一样。伏案是否计入专注时长可在设置里开关
- **看不到驼背**。正面视角拿不到脊柱侧面轮廓，坐姿只用肩线倾角估算，不是医学结论
- **只支持 Windows**。托盘和窗口监视依赖 Win32 API
- **应用分类靠关键词**。游戏 exe 名和中文标题不匹配默认列表时会被静默归到"中性"，需要自己维护关键词表
- 摄像头检测受光照和坐姿影响，阈值需要按自己的环境校准
